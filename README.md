# AcademiaConnect 🎓

A web-based academic and career portal designed to help students manage their academic profile, skills, internships, jobs, and applications.

## 🚀 Features

- Student Dashboard
- Student Profile
- Skills Management
- Jobs & Internship Opportunities
- Admin Dashboard
- Student Registration & Login
- REST API integration
- Dynamic student data
- Update student skills through API

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API
- CORS
